# Xygeni Extensions

This directory contains extensions for the Xygeni software supply chain security platform.

## Contents

- **[custom_detectors/](custom_detectors/)** - Custom security detectors (secrets, IaC, CI/CD misconfigurations)
- **[custom_remediations/](custom_remediations/)** - Remediation playbooks for security issues
- **[report_upload/](report_upload/)** - Third-party report converters for importing external tool results
- **[exporter/](exporter/)** - Export scripts for extracting data from third-party tools

See the [top-level README](../README.md) for detailed documentation on each extension type.
